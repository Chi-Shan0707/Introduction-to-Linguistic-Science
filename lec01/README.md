## 一、课程引入：什么是语言学？

语言学（Linguistics）远不止"学一门语言"那么简单。作为一门系统的科学，语言学研究的核心对象是**人类语言这一独特的认知能力与符号系统**。它追问的根本问题是：

- 语言究竟是什么？
- 语言为什么只有人类拥有？
- 语言的内部结构如何运作？
- 语言与大脑、社会、文化、技术之间有何关系？

本讲作为整门课程的导言，并不深入某个具体子领域，而是为学生描绘一幅**语言学学科的全景地图**，帮助你在后续十五讲中找到方向。

## 三、语言学的核心问题：语言何以区分人与动物？

### 3.1 问题的提出

"复杂的语言区分人与动物？"——这是本讲抛出的一个根本性问题。

人类并不是唯一拥有交流系统的物种。蜜蜂通过舞蹈传递食物位置信息，鸟类的鸣叫具有领地宣示和求偶功能，黑猩猩能使用手势和声音进行基本的社会互动。但人类语言与这些动物交流系统之间存在**质的差异**。

### 3.2 人类语言的独特性质

现代语言学认为，人类语言至少具有以下动物交流系统所不具备的特征（通常称为 **Hockett 的设计特征** 的核心子集）：

| 特征 | 英文 | 含义 | 动物交流是否具备？ |
|------|------|------|-------------------|
| **任意性** | Arbitrariness | 语音形式与意义之间没有必然的物理联系（"狗"为什么叫 /gou/ 没有道理可讲） | 部分具备 |
| **能产性/创造性** | Productivity / Creativity | 可以用有限的规则和成分生成无限的、从未说过的新句子 | ❌ 不具备 |
| **移位性** | Displacement | 可以谈论此时此地不存在的事物（过去、未来、虚构） | 极少数有限具备 |
| **二层性** | Duality of Patterning | 语言在底层有无意义的音素层，上层是有意义的词素层 | ❌ 不具备 |
| **递归性** | Recursion | 可以在句子中无限嵌套句子（"我知道你认为他相信她来了"） | ❌ 不具备 |

> **核心论点**：正是这些特征——尤其是**能产性**和**递归性**——使人类语言成为一种"无限的、离散的"符号系统，从根本上区别于动物交流的"有限的、连续的"信号系统。

### 3.3 应用语言学

课程提及了**应用语言学**（Applied Linguistics），这是一个广义概念，指将语言学理论和方法应用于实际问题的领域，包括但不限于：

- 语言教学（外语教学、对外汉语教学）
- 语言规划与政策
- 词典编纂
- 语言翻译
- 自然语言处理
- 语言康复

应用语言学不是语言学的某个子领域，而是一种**研究取向**——它关心的是"语言学知识能用来做什么"。

## 四、语言的三个平面：语法、语义、语用

### 4.1 三平面理论概述

现代语言学分析语言现象时，通常区分三个层次的分析平面：

| 平面 | 英文 | 关注的问题 | 核心概念 |
|------|------|-----------|----------|
| **语法**（句法）| Syntax / Grammar | 句子的形式结构是什么？词是如何组合成句的？ | 词序、句法树、短语结构、语态 |
| **语义** | Semantics | 句子表达的意义是什么？词与词之间的意义关系如何？ | 真值条件、语义角色、同义、歧义 |
| **语用** | Pragmatics | 在具体语境中，说话人通过句子实际传达了什么意图？ | 言语行为、含义（implicature）、指示、预设 |

> **直觉理解**：
> - **语法**关注"这句话合法吗？"——形式是否正确
> - **语义**关注"这句话是什么意思？"——字面意义
> - **语用**关注"说话人为什么要说这句话？"——语境中的意图

### 4.2 经典例句分析

课程以一个经典的对比例句展示了**语法与语义的分离**：

```
句A：主席团坐在台上。
句B：台上坐着主席团。
```

#### 语法层面的差异

| 对比维度 | 句A：主席团坐在台上 | 句B：台上坐着主席团 |
|----------|---------------------|---------------------|
| **句式类型** | 常规主谓宾（SVO） / 主谓结构 | 存现句（存在句） |
| **主语** | "主席团"（施事/客体作主语） | "台上"（处所词作主语） |
| **谓语结构** | "坐" + "在台上"（动词 + 介宾补语） | "坐着" + "主席团"（动词 + 体标记 + 宾语） |
| **信息结构** | "主席团"是话题（已知信息） | "主席团"是新信息（焦点） |
| **语态特征** | 主动句 | 表面上类似被动/中动结构 |

#### 语义层面的相同

尽管语法结构截然不同，两句的**命题意义**基本一致：

- 都描述了"主席团在台上"这一空间关系
- 真值条件相同：两句在同样的现实情境下同真同假
- 语义角色关系一致："主席团"是客体（Theme），"台上"是处所（Location）

#### 语用层面的微妙差异

在具体语境中，两句的选用有细微区别：

- **句A**倾向于**话题已知**的场景（"主席团呢？"——"主席团坐在台上。"）
- **句B**倾向于**引入新信息**的场景（"台上什么情况？"——"台上坐着主席团。"）

#### 小结

```
        句A                句B
      "主席团坐在台上"    "台上坐着主席团"
           │                   │
     ┌─────┴─────┐       ┌─────┴─────┐
     │  语法：不同  │       │  语法：不同  │    ← 句式、主语、信息结构均不同
     │  语义：相同  │       │  语义：相同  │    ← 命题意义、真值条件一致
     │  语用：微妙差异│      │  语用：微妙差异│   ← 话题-焦点分布不同
     └───────────┘       └───────────┘
```

> **核心启示**：**相同的语义可以用不同的语法形式来表达**。这是语言学中最基本的发现之一——形式与意义之间的映射关系不是一一对应的，而是**多对多**的。这一发现直接催生了句法学、语义学、语用学作为独立子领域的必要性。

## 五、计算语言学：当语言遇上计算机

### 5.1 什么是计算语言学？

**计算语言学**（Computational Linguistics）是语言学与计算机科学的交叉领域，旨在用计算方法来建模、处理和分析人类语言。

课程在第1讲就引入计算语言学的概念，暗示了**数字化、计算化**已经成为现代语言学不可忽视的方法论维度。

### 5.2 核心研究方向

| 方向 | 英文 | 典型任务 |
|------|------|----------|
| 自然语言处理 | NLP | 分词、词性标注、句法分析、命名实体识别 |
| 机器翻译 | MT | 将一种语言自动翻译为另一种语言 |
| 语音识别与合成 | ASR & TTS | 将语音转为文字，或将文字转为语音 |
| 信息检索 | IR | 从海量文本中提取相关信息 |
| 对话系统 | Dialogue Systems | 构建能与人自然对话的智能体 |
| 语言模型的构建 | Language Modeling | 对语言的概率分布进行建模（如GPT系列） |

### 5.3 从规则到统计到深度学习

计算语言学的方法论经历了三次范式转移：

```
1950s-1980s：规则方法（Symbolic / Rule-based）
    → 人工编写语法规则，用逻辑推理处理语言
    → 局限：规则无法覆盖语言的全部复杂性

1990s-2010s：统计方法（Statistical）
    → 从大规模语料中自动学习语言模式
    → 里程碑：隐马尔可夫模型（HMM）、条件随机场（CRF）、支持向量机（SVM）

2010s-至今：深度学习方法（Deep Learning）
    → 用神经网络自动学习语言的多层抽象表征
    → 里程碑：Word2Vec、Transformer、BERT、GPT系列
```

> **与本课程的联系**：第15讲（语言与AI）将深入探讨大语言模型的最新进展及其与语言学的关联。计算语言学不只是"应用"——它反过来也在推动语言学理论本身的发展。

## 七、语言学研究的数学化趋势

### 7.1 从文科到理科的转变

传统观念中，语言学往往被归入"人文学科"。然而，现代语言学的研究越来越依赖**数学工具**和**量化方法**。课程特意提到张梦翰研究员（数学出身、在智能复杂体系实验室工作）并非偶然——它代表了一种趋势：

- **计量语言学**（Quantitative Linguistics）：用统计方法研究语言规律
- **计算语言学**（Computational Linguistics）：用算法建模语言
- **数理语言学**（Mathematical Linguistics）：用形式化方法（如形式语言理论、自动机理论）描述语言结构
- **实验语言学**（Experimental Linguistics）：用实验设计和统计分析验证语言学假设

### 7.2 语言学中的数学工具举例

| 数学工具 | 语言学应用 |
|----------|-----------|
| 概率论与统计 | 语料库语言学、语言变异的统计分析 |
| 信息论 | 语音信号的编码与传递效率 |
| 图论 | 句法树、依存句法分析 |
| 矩阵与线性代数 | 词向量（Word Embeddings）、语义空间 |
| 微分方程 | 语言演化的动力学模型 |
| 贝叶斯推理 | 语言习得的计算建模 |
| 最优化理论 | 句法分析中的概率模型 |

> **给大一学生的建议**：不要被"数学"两个字吓到。语言学的数学化是一个**渐进的过程**——你不需要成为数学家才能做语言学，但具备一定的数学素养会让你在理解前沿研究时游刃有余。

5. 复旦IMOLL的研究方向中，你对哪个最感兴趣？为什么？

### 9.2 延伸阅读

- **入门推荐**：
  - Victoria Fromkin 等, *An Introduction to Language*（语言学经典教材，深入浅出）
  - Steven Pinker, *The Language Instinct*（《语言本能》，面向大众的语言学科普）
- **关于语言独特性**：
  - Charles Hockett, "The Origin of Speech"（1960）——提出著名的设计特征清单
  - Hauser, Chomsky & Fitch, "The Faculty of Language: What Is It, Who Has It, and How Did It Evolve?" (*Science*, 2002)
- **关于语法与语义的分离**：
  - 吕叔湘《汉语语法分析问题》（汉语语法研究的经典文献）
  - 朱德熙《语法答问》（对汉语语法现象的精辟分析）
- **关于计算语言学**：
  - Daniel Jurafsky & James Martin, *Speech and Language Processing*（NLP领域的权威教材）

| 语法/句法 | Syntax / Grammar | 研究句子形式结构与组合规则的平面 |
