## 一、核心命题：人类是智能的最终形态吗？

讲座开篇抛出了一个极具挑衅性的问题——人类智能是否是进化的终点？从大模型和前沿AI研究者的视角看，人类智能在当前阶段反而可能是一种**相对落后的形态**。大模型所能感知和处理的信号，已经在某些维度上超越了人类的认知能力。

这引出一个更深层的问题：随着环境的剧变，智能是否会以更"数字化的"、更"模型化"的方式延续？而人类本身——在大模型研究者的视角下——是否正在成为训练智能体的"养料"（训练数据的来源）？

> 这并非贬低人类，而是重新定义人类在智能演化链条中的位置：从"智能的终极载体"变为"智能的种子与土壤"。

## 二、智能体的三大核心能力

讲座将智能体（Agent）的能力分解为三个层次：

| 层次 | 能力 | 说明 |
|------|------|------|
| **感知** | 感知环境 | 通过语言、视觉、运动等多模态信号接收外部信息 |
| **理解** | 理解环境 | 对信息进行思考、推理与决策 |
| **行动** | 与真实世界互动 | 将决策转化为具体行动（Action） |

这一框架与经典的感知-认知-行动循环一致，但讲座特别强调了**语言在其中的枢纽地位**。

## 三、语言即世界：语言作为知识的压缩

### 3.1 核心论点

**语言是现实世界的压缩（Language is the compression of real world）。**

语言之所以能成为连接模型与世界知识的关键桥梁，在于它具备两个特性：
- **压缩性**：将复杂的世界经验抽象为有限的符号序列
- **传承性**：以可传播的形式记录人类对世界的认知，实现跨时空的知识传递

这意味着，对语言的建模本质上就是对世界知识的建模。GPT系列"预测下一个词"的训练目标看似简单，实际上迫使模型在内部构建了一个关于世界的隐式表征。

### 3.2 从语言建模到世界理解

大模型的发展路径：
1. **起步**：对语言的统计建模（n-gram → 神经语言模型）
2. **涌现**：随规模扩大（如GPT-3），模型展现出未经特定训练的"通用"能力
3. **统一**：语言、视觉、音频、运动等不同模态在深层表征上趋于一致

## 四、大模型的技术演进

### 4.1 架构之争

| 架构 | 代表 | 核心思路 |
|------|------|----------|
| **Encoder-only** | Google (BERT) | 双向编码，理解语言 |
| **Encoder-Decoder** | Meta (BART, T5) | 编码-解码，序列转换 |
| **Decoder-only** | OpenAI (GPT系列) | 从始至终坚持，自回归生成 |

历史证明，OpenAI的Decoder-only路线在规模化后展现出最强的通用能力。这背后暗含一个哲学：

> **"What I cannot create, I do not understand."** — Feynman
> 
> 只有能生成（create）语言的模型，才是真正理解（understand）了语言。

### 4.2 Bitter Lesson 与柏拉图表征

**Bitter Lesson**（Richard Sutton）：在AI发展史上，那些依赖人类先验知识的方法，最终都会被纯粹依靠规模和算力的通用方法超越。人类精心设计的特征工程、语言学规则，在足够大的数据和算力面前都显得多余。

**柏拉图表征假说（Platonic Representation）**：研究表明，不同架构、不同训练目标的优秀模型，在处理语言、视觉、音频等多种模态时，其内部表征（representation）趋于相似。这暗示存在一个"理想的"表征空间，所有好的模型都在逼近它——如同柏拉图的理念世界。

## 五、通用AI的两大瓶颈

讲座将通用人工智能（AGI）的实现归结为两大缺失组件：

### 5.1 缺乏可泛化的打分器（Scorer）

当前的评估体系是碎片化的——每个任务有自己的benchmark。AGI需要一个能在**任意任务**上给出准确评分的通用评估器。没有它，我们无法判断模型是否"真正"理解了什么。

### 5.2 缺乏强理解的执行器（Executor）

即使有了完美的规划，如果执行器无法将高阶指令转化为精确的物理操作，智能体仍无法与现实世界有效交互。这正是具身智能（Embodied AI）面临的核心挑战。

## 六、"大脑-小脑"协同架构

为解决语言指令到物理执行的鸿沟，讲座提出了一个启发自神经科学的架构隐喻：

| 组件 | 类比 | 功能 |
|------|------|------|
| **"大脑"** | 大语言模型 | 生成高阶动作指令、规划与推理 |
| **"小脑"** | 低层控制器 | 在虚拟环境中学习稳定、精确地执行动作 |

这一架构的直觉是：大模型擅长"想"但不擅长"做"，而低层控制器擅长"做"但需要精确的指令。"大脑"给出"端到那端"的语义指令，"小脑"负责将每个关节的运动学细节补全。

> 与Lecture 11（语言与大脑）中讨论的**生物学小脑**形成呼应：生物学小脑只占大脑体积10%，却含有约80%的神经元，负责精细运动控制。AI架构中的"小脑"同样承担着将抽象意图转化为精确执行的角色。

## 八、强化学习：从经典算法到 Agentic RL

强化学习（RL）是让AI在特定任务上超越人类的关键技术。从AlphaGo到AlphaFold，RL展现了在规则明确的环境中超越人类能力的潜力。而当前最前沿的方向——**Agentic RL**——则是让大模型从"被动回答问题"进化为"主动规划与行动"的核心训练范式。

---

### 8.1 RL 的基本框架：马尔可夫决策过程（MDP）

一切RL问题都可以形式化为一个MDP：

```
状态 s_t → 智能体选择动作 a_t → 环境返回奖励 r_t + 新状态 s_{t+1}
```

五个要素：
- **S**（State Space）：环境可能的所有状态
- **A**（Action Space）：智能体可能的所有动作
- **P**（Transition）：状态转移概率 P(s'|s,a)
- **R**（Reward）：奖励函数 r(s,a)
- **γ**（Discount Factor）：折扣因子，权衡即时奖励与远期奖励

目标：学习一个**策略（Policy）** π(a|s)，使得累积折扣奖励的期望最大。

---

### 8.2 经典算法家族

RL算法可分为三大类，沿着"值函数 → 策略 → 两者结合"的路径演进：

#### （1）基于值函数的方法（Value-Based）

核心思想：不直接学策略，而是学一个**价值函数** Q(s,a)，表示"在状态s采取动作a后，未来能获得的期望总奖励"。

| 算法 | 年代 | 关键创新 |
|------|------|----------|
| **Q-Learning** | 1992 | 离策略（off-policy），用贝尔曼方程迭代更新 Q 值 |
| **DQN** | 2015 (DeepMind) | 用神经网络近似Q函数，引入经验回放（Experience Replay）和目标网络（Target Network）稳定训练 |

DQN 是深度学习 + RL 的里程碑——2015年在Atari游戏上达到人类水平。

**DQN训练流程**：
1. 智能体与环境交互，收集 (s, a, r, s') 四元组存入回放缓冲区
2. 从缓冲区随机采样一批数据（打破时序相关性）
3. 用神经网络预测 Q(s,a)，与目标值 y = r + γ·max_a' Q(s',a'; θ_target) 计算损失
4. 梯度下降更新网络参数
5. 定期将主网络参数复制到目标网络（防止"追自己尾巴"）

#### （2）基于策略的方法（Policy-Based）

核心思想：直接参数化策略 π_θ(a|s)，通过梯度上升最大化期望奖励。

| 算法 | 年代 | 关键创新 |
|------|------|----------|
| **REINFORCE** | 1992 | 最简单的策略梯度算法，蒙特卡洛采样 |
| **A3C** | 2016 (DeepMind) | 异步多线程并行训练，大幅加速 |

策略梯度公式（核心中的核心）：

```
∇_θ J(θ) = E[ Σ ∇_θ log π_θ(a_t|s_t) · R_t ]
```

直觉：如果某条轨迹的回报 R_t 高，就增大产生那些动作的概率；回报低，就减小。

**问题**：方差极大。一条好的轨迹和一条坏的轨迹之间差距可能巨大，导致梯度估计不稳定。

#### （3）Actor-Critic（演员-评论家）

结合值函数和策略两路的优势——这成为现代RL的标准范式：

- **Actor（演员）**：策略网络 π_θ(a|s)，负责选择动作
- **Critic（评论家）**：价值网络 V_φ(s) 或 Q_φ(s,a)，负责评估动作的好坏

Critic 提供一个**基线（baseline）**，大幅降低策略梯度的方差。

| 算法 | 年代 | 关键创新 |
|------|------|----------|
| **A2C / A3C** | 2016 | Advantage Actor-Critic，用优势函数 A(s,a) = Q(s,a) - V(s) 替代原始回报 |
| **PPO** | 2017 (OpenAI) | **Proximal Policy Optimization**——当前最广泛使用的RL算法 |
| **SAC** | 2018 | Soft Actor-Critic，引入最大熵框架，鼓励探索 |
| **TD3** | 2018 | Twin Delayed DDPG，解决连续动作空间的Q值过估计问题 |

---

### 8.3 PPO：现代 RL 的基石

PPO（Proximal Policy Optimization）之所以成为主流，在于它解决了一个根本问题：**如何安全地更新策略而不让模型"崩掉"？**

**核心思想**：限制每次策略更新的幅度。

```python
# PPO 的核心损失函数
ratio = π_new(a|s) / π_old(a|s)           # 新旧策略的概率比
clipped_ratio = clip(ratio, 1-ε, 1+ε)     # 裁剪到 [1-ε, 1+ε]（通常 ε=0.2）

L_CLIP = min(
    ratio × Advantage,                      # 正常的策略梯度
    clipped_ratio × Advantage               # 裁剪后的策略梯度
)
```

**为什么需要裁剪？** 如果某次更新让策略变化过大，模型可能跳到一个很差的区域，之后无法恢复（策略崩溃）。裁剪确保每一步都是"保守的前进"。

**PPO训练流程**：
1. 用当前策略收集一批轨迹数据
2. 计算每个时间步的优势估计（Advantage），通常用GAE（Generalized Advantage Estimation）
3. 对同一批数据进行多轮（通常3-10个epoch）的梯度更新
4. 通过裁剪机制确保策略不会偏离太远
5. 重复

PPO 的最大优势：**稳定、易调参、不崩溃**。这三个品质使它成为从游戏到机器人到大模型对齐的首选算法。

### 8.4 RLHF：让大模型对齐人类意图

当RL遇上大语言模型，最核心的应用是**RLHF（Reinforcement Learning from Human Feedback）**——这是ChatGPT之所以"好用"的关键技术。

#### 三阶段训练流程：

**阶段一：监督微调（SFT）**

用人工编写的高质量对话数据微调预训练模型，使其学会对话格式。

```
输入：用户问题
输出：期望的回答（人工撰写）
目标：最小化交叉熵损失
```

**阶段二：奖励模型训练（Reward Model）**

人类标注员对模型生成的多个回答进行排序（如 A > B > C），训练一个打分模型：

```
输入：一个 (问题, 回答) 对
输出：一个标量分数 r(question, answer)
训练信号：排序偏好 → Bradley-Terry 模型 → 交叉熵损失

L_RM = -log(σ(r(x, y_w) - r(x, y_l)))
# y_w: 人类偏好的回答（winner）
# y_l: 人类不偏好的回答（loser）
```

**阶段三：PPO 强化学习优化**

用奖励模型作为替代奖励信号，通过PPO优化语言模型策略：

```
状态 s = 对话上下文
动作 a = 生成的token
奖励 r = 奖励模型打分 - β × KL散度（防止偏离SFT模型太远）

L_RLHF = E[r_RM(x, y)] - β × KL(π_θ || π_SFT)
```

其中 KL 惩罚项是关键——没有它，模型会找到奖励模型的漏洞（reward hacking），生成人类看起来无意义但奖励模型给高分的文本。

#### RLHF 的局限性：
- **奖励模型不完美**：它只是人类偏好的近似，存在reward hacking风险
- **标注成本极高**：需要大量人工排序
- **训练不稳定**：PPO本身对超参数敏感，在大模型上更加如此
- **KL约束太紧会限制能力**：太松会偏离安全边界

---

### 8.5 后 RLHF 时代：DPO、GRPO 与 R1-Zero

#### DPO（Direct Preference Optimization, 2023）

**核心洞见**：RLHF的奖励模型和PPO优化可以合并为一步！

```
L_DPO = -log σ(β × (log π_θ(y_w|x)/π_ref(y_w|x) - log π_θ(y_l|x)/π_ref(y_l|x)))
```

DPO直接用偏好数据优化策略，**完全跳过奖励模型训练和PPO**。优势：
- 训练简单（就是普通的分类损失）
- 稳定得多
- 不需要在线采样

代价：灵活性降低，不能在训练过程中动态获取新反馈。

#### GRPO（Group Relative Policy Optimization, DeepSeek 2025）

DeepSeek-R1 的核心训练算法。对 PPO 的关键改进：

**去掉 Critic 网络**——不用训练单独的价值函数来估计基线，而是用**同一问题的多个采样结果的相对排名**作为基线。

```
# GRPO 核心思路
1. 对同一个问题 x，采样 G 个回答 {y_1, y_2, ..., y_G}
2. 用奖励模型给每个回答打分 {r_1, r_2, ..., r_G}
3. 计算组内标准化优势：A_i = (r_i - mean(r)) / std(r)
4. 用类似 PPO 的裁剪目标更新策略
```

优势：**省掉一个完整的Critic网络**（在大模型场景下就是省掉一个同等规模模型的训练），显著降低显存和计算成本。

#### DeepSeek-R1-Zero：纯RL涌现推理能力

DeepSeek-R1最震撼的发现：**不给任何SFT数据、不给任何链式思维示范，只用纯RL训练，模型会自发涌现出推理能力。**

训练流程：
1. 基座模型：DeepSeek-V3（标准的预训练大模型）
2. 规则化奖励：对数学和代码任务，用**规则判定**（答案对不对、代码能不能跑）而非神经网络奖励模型
3. 纯GRPO训练：只给问题，让模型自己生成解题过程和答案
4. 涌现现象：模型在训练过程中自发学会了：
   - **自我反思（Self-Reflection）**："等等，让我重新检查这一步"
   - **多路径尝试**：先试一种方法，不行换另一种
   - **中间验证**：在推理过程中检查中间结果是否合理
   - **"Aha Moment"**：模型自己发现思路错误并纠正

这一发现的意义：**推理能力不是需要"教"的，而是可以通过RL"激发"的。** 基座模型在预训练阶段已经学到了足够的世界知识，RL的作用是教会它"如何有效地使用这些知识"。

### 8.6 Agentic RL：让模型学会行动

"Agentic RL"是指用强化学习训练大模型具备**智能体能力**——不只是回答问题，而是**主动规划、调用工具、与环境交互**。

#### 核心训练范式

**（1）Tool Use Training（工具使用训练）**

```
环境状态：用户请求 + 可用工具列表（搜索、代码执行、数据库查询等）
动作空间：生成文本 / 调用工具
奖励信号：任务是否完成（二元） / 完成质量（连续值）

训练方式：
- 先用SFT让模型学会工具调用的格式
- 再用RL让模型学会"什么时候调用哪个工具"
```

关键挑战：动作空间巨大且稀疏。在一个100步的推理过程中，可能只有3步需要调工具，模型需要学会精确判断时机。

**（2）Multi-Turn RL（多轮交互RL）**

传统的RLHF是单轮的：给一个问题，生成一个回答。Agentic RL需要多轮：

```
Turn 1: 模型思考 → "我需要搜索X"
Turn 2: 接收搜索结果 → 思考 → "还需要执行代码计算Y"  
Turn 3: 接收代码输出 → 思考 → 生成最终答案
```

奖励信号只在最终步骤给出（或分阶段给出），中间步骤的信用分配（credit assignment）是核心难题。

**（3）过程奖励模型（Process Reward Model, PRM）**

传统RLHF的奖励模型只看最终结果（Outcome Reward Model, ORM）。PRM对推理的**每一步**打分：

```
问题: "求解 x^2 + 3x + 2 = 0"
  → 步骤1: "使用因式分解"              → PRM打分: 0.9 ✓
  → 步骤2: "x^2 + 3x + 2 = (x+1)(x+2)" → PRM打分: 0.95 ✓
  → 步骤3: "所以 x = -1 或 x = -2"      → PRM打分: 1.0 ✓
```

PRM的优势：信号更密集，信用分配更精确。劣势：标注成本极高（需要人类对每一步评分）。

DeepSeek-Math 和 Math-Shepherd 的替代方案：**自动标注PRM**——用蒙特卡洛采样估计每一步的正确概率，无需人工标注。

**（4）搜索时的推理强化（Test-Time Compute Scaling）**

这是2024-2025年最热的方向之一。核心思想：**不在训练时花更多算力，而是在推理时花更多算力来"想清楚"。**

| 方法 | 策略 |
|------|------|
| **Best-of-N** | 生成N个答案，选奖励最高的 |
| **Tree of Thought** | 在推理树上做搜索（BFS/DFS） |
| **MCTS + RL** | 蒙特卡洛树搜索 + 学习的价值函数引导 |
| **Beam Search + PRM** | 每一步保留top-k候选，用PRM剪枝 |

直觉：就像人类遇到难题时会"多想几遍、换几种思路"，模型也可以在推理时分配更多计算资源来提高回答质量。

---

### 8.7 世界模型 + RL：从AlphaGo到通用智能体

回到讲座的主题——"大脑-小脑"架构中的"大脑"部分，本质就是一个**世界模型（World Model）**：

```
世界模型 W: (s_t, a_t) → s_{t+1}
```

它预测"如果我采取动作a，世界会变成什么样"。

| 系统 | 世界模型 | RL组件 | 成果 |
|------|----------|--------|------|
| **AlphaGo** | 棋盘状态完全可知 | MCTS + 策略网络 | 围棋超人类 |
| **AlphaZero** | 自我对弈构建世界模型 | MCTS + 自博弈RL | 通用棋类 |
| **MuZero** | 无需规则，自己学世界模型 | MCTS + 学到的模型 | 多游戏通用 |
| **Dreamer** | 在潜空间中想象未来 | Actor-Critic in dream | 机器人控制 |
| **DayDreamer (2022)** | 学习机器人动力学模型 | 在"梦境"中训练策略 | 真实机器人6个任务 |
| **RoboCat (DeepMind 2023)** | 大规模视觉-语言-动作模型 | 自改进循环 | 多种机器人操作 |
| **RT-2 (Google 2023)** | 视觉-语言模型直接输出动作 | 大规模预训练 + 微调 | 语义理解驱动的机器人 |

**趋势**：世界模型越来越"大"（从棋盘到图像到语言），RL的"动作"越来越抽象（从落子到像素到自然语言指令）。

### 8.8 Agentic RL 的训练流程总结

将上述技术串起来，一个典型的现代 Agentic RL 训练流水线如下：

```
┌─────────────────────────────────────────────────────┐
│  Stage 1: Pre-training（预训练）                      │
│  海量文本/多模态数据 → 自回归下一个token预测            │
│  目标：建立世界知识基座                               │
├─────────────────────────────────────────────────────┤
│  Stage 2: SFT（监督微调）                             │
│  高质量对话/推理/工具使用数据 → 监督学习                │
│  目标：教会格式和基本能力                              │
├─────────────────────────────────────────────────────┤
│  Stage 3: Reasoning RL（推理强化学习）                 │
│  数学/代码/逻辑任务 + GRPO/PPO → 纯RL训练             │
│  目标：激发深度推理和自我纠错能力                       │
│  关键：涌现 "aha moment"、多路径探索、反思             │
├─────────────────────────────────────────────────────┤
│  Stage 4: Alignment RL（对齐强化学习）                │
│  人类偏好数据 + DPO/RLHF → 安全性和有用性对齐           │
│  目标：让模型的行为符合人类期望                         │
├─────────────────────────────────────────────────────┤
│  Stage 5: Agentic RL（智能体强化学习）                 │
│  多轮工具使用环境 + 过程奖励 → 多步决策训练             │
│  目标：学会主动规划、调用工具、与环境交互               │
│  关键：稀疏奖励、长程信用分配、过程奖励模型             │
└─────────────────────────────────────────────────────┘
```

每一层都建立在前一层的基础上——没有预训练的世界知识，RL训练就是空中楼阁；没有SFT的格式能力，模型不知道如何表达推理；没有推理RL的"深度思考"能力，Agentic RL的多步规划就无法实现。

### 8.9 从RL视角重新理解讲座的核心观点

回到讲座开篇的两个瓶颈：

- **"缺乏可泛化的打分器"** → 对应RL中的**奖励函数设计**难题。在开放世界中，如何定义"做得好不好"？这比围棋的一盘胜负判断要难得多。
- **"缺乏强理解的执行器"** → 对应RL中的**策略在物理世界的迁移**问题。模拟器中训练的策略能否迁移到真实世界（Sim2Real Gap）？

而"大脑-小脑"架构的RL解读：
- **大脑 = World Model + Planner**：用大模型理解世界、规划动作序列
- **小脑 = Low-level Policy**：用RL训练的低层控制器执行精细动作
- 两者通过层级RL（Hierarchical RL）的框架协同：大脑给出高阶目标，小脑优化局部执行
